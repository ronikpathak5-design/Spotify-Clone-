# Spotify Clone 🎵

Welcome to my very first GitHub project! This repository contains a frontend clone of the Spotify web interface, built using pure HTML and CSS.

## 🚀 Features
* **Responsive Sidebar & Navigation:** Styled using CSS Flexbox, featuring custom icons and hover effects[cite: 1, 2].
* **Sticky Navigation Bar:** Includes functional-style buttons like "Explore Premium" and "Install App"[cite: 2].
* **Dynamic Card Grid:** Showcases recently played tracks, trending songs, and featured charts with hover shadows[cite: 1, 2].
* **Fixed Music Player Bar:** A bottom-anchored player complete with playback controls and custom progress range sliders[cite: 1, 2].

## 🛠️ Built With
* **HTML5**[cite: 2]
* **CSS3** (Flexbox, Media Queries, Custom Styling)[cite: 1]
* **FontAwesome** (Icons)[cite: 2]
* **Google Fonts** (Montserrat)[cite: 2]

## 📂 Project Structure
* `project.html` - The core HTML structure of the web application[cite: 2].
* `proj.css` - The stylesheet containing layout designs, responsive grid layouts, and media queries[cite: 1].
